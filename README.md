# BTC 기준선 대시보드

비트코인 가격을 예측하지 않고, 미리 정해둔 기준선(가격 구간) 대비 현재가의 위치를 자동으로 계산해 보여주는 대시보드입니다. 설계 원칙과 로드맵은 프로젝트 논의 문서를 따릅니다.

## 현재 구현 범위 (1단계)

- BTC 실시간 가격 + 24시간 변동률 (CoinGecko 무료 API)
- 50일/200일 이동평균 자동 계산
- 구간 게이지: 사용자가 설정한 기준선 대비 현재가 위치 자동 판정
- 가격 차트: 종가 + 50일선 + 200일선 오버레이, 기간(4개월/1년/2년) 전환
- 요약 카드: 현재가 vs 이동평균 괴리율, 골든/데드크로스 상태
- 설정 화면에서 기준선(구간) 직접 추가/수정/삭제, `localStorage`에 저장

앱은 "사라/팔아라"를 말하지 않습니다 — 조건 충족 여부와 다음에 확인할 지점만 보여주고, 최종 판단은 사용자 몫으로 남깁니다.

## 다음 단계

- 2단계: ETF 자금 흐름, 청산 데이터 등 반자동 입력 폼
- 3단계: 매매 장부(체결 기록 → 잔여 목표/평균단가 자동 계산)
- 4단계: A지표 종합판정 + 레이더/히트맵/추세선 시각화
- 5단계: 종합 판단 엔진(여러 신호를 하나의 카드로 통합)
- 6단계: 기준선 도달 알림, 거래소 API 연동

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
```

가격 데이터는 CoinGecko 공개 API(`api.coingecko.com`)를 인증 없이 호출합니다. 외부 네트워크가 차단된 환경에서는 가격 로딩이 실패하며 화면에 오류 메시지가 표시됩니다.
