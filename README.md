# 가늠자

가격을 예측하지 않고, 미리 정해둔 기준선(가격 구간) 대비 현재가의 위치를 자동으로 계산해 보여주는 대시보드입니다. 설계 원칙과 로드맵은 프로젝트 논의 문서를 따릅니다.

## 현재 구현 범위

**1단계 — 가격 대시보드**
- BTC 실시간 가격 + 24시간 변동률 (Binance 무료 API, 인증 불필요)
- 50일 / 200일 / **50주(350일)** 이동평균 자동 계산
- 구간 게이지: 사용자가 설정한 기준선 대비 현재가 위치 자동 판정
- **캔들차트**(TradingView `lightweight-charts`) — 라방 화면과 같은 구성:
  - 일봉 캔들 + 50일선 + 200일선 + 50주선
  - **불마켓밴드**(Bull Market Support Band = 20주 SMA / 21주 EMA) 채워진 밴드
  - 실현가격 · 밸런스가격 점선 (수동 입력 시)
  - 골든/데드크로스 화살표 마커
  - **RSI(14) 서브차트** (70/30 기준선)
  - 봉 단위 전환: 1분 / 1일 / 1주. 세 단위 모두 그 봉 자체로 새로 계산한 이평선·RSI를 표시(1일=50일/200일/50주, 1주=50주/200주, 1분=50분/200분). 불마켓밴드는 1일·1주에만 있음 — 20/21분 SMA·EMA로 부를 근거가 없어 1분에는 뺐음. 보이는 범위는 드래그·핀치줌으로 직접 조절(고정 기간 버튼 없음)
  - 오버레이 켜기/끄기: 이평선·불마켓밴드·RSI·크로스마커를 각각 토글해서 원하는 것만 볼 수 있음
- 요약 카드: 현재가 vs 이동평균 괴리율, 골든/데드크로스 상태
- 설정 화면에서 기준선(구간) 직접 추가/수정/삭제, `localStorage`에 저장

**2단계 — 반자동 데이터 입력**
- ETF 자금 흐름 매일 입력 → 연속 순유입 일수 자동 카운트, 막대 차트로 시각화
- 청산 금액 / 미결제약정 / 펀딩비 매일 입력
- 실수요 판정 카드: "ETF 3일 이상 연속 순유입 + 펀딩비 급등 없음 + 미결제약정 안정화"를 자동 체크해 실수요/스퀴즈 의심/판단 보류를 판정
- 입력이 부족한 조건은 항상 "❓ 판단 보류"로 표시하고 추측하지 않음

**3단계 — 매매 장부**
- 매매 계획(보유량, 목표 매도 비율) 설정 — 값을 바꿀 때마다 변경 이력에 자동 기록되어 감정적으로 자주 바꾸는 것을 방지
- 체결 기록(매도/매수, 수량, 체결가) 입력 → 누적 매도량, 잔여 목표, 평균 체결가 자동 계산
- 매도 계획 진행률 바로 목표 대비 현재 진행 상황을 한눈에 확인

**4단계 — A지표 종합판정**
- 19개 지표 판정표: 8개는 기존 데이터로 자동 계산(불마켓밴드, 50/200일선, **50주선**, 골든·데드크로스, ROI 사이클, ETF 흐름, 펀딩비), 9개는 직접 긍정/대기/경계 선택, MVRV·DXY 2개는 숫자 입력 시 자동 임계값 판정
- EWY/EWJ는 설계 문서 지시대로 참고 메모만 남기고 점수 집계에서 제외
- 레이더 차트(지금 이 순간의 모양) · 신호등 히트맵(빠른 스캔) · 종합 점수 추세선(날짜별 흐름) 3종 시각화
- A지표 요약 카드: 총점 / 긍정·대기·경계·미입력 개수

**5단계 — 종합 판단 엔진**
- 홈 화면 최상단 종합 판단 카드: 가격 위치·A지표 점수·실수요 판정·사이클 위치를 한 카드로 통합
- 가격 구간 톤과 A지표 점수 톤이 일치하는지 자동 비교 → 일치/불일치 판정, 실수요가 "파생시장 효과 의심"이면 판단 보류를 추가로 권고
- 신호 불일치 시 "⚠ 신호 불일치" 경고 박스로 강조 표시 (숨기지 않음)
- 다음에 확인할 것: 현재 구간의 상/하단 기준선 돌파·이탈 시 어떤 구간으로 이동하는지 자동 안내

**7단계 — 다중 자산 + 분할매수 계획**
- 자산 탭으로 전환: 비트코인 외에 SPY 2X · QQQ · SOXL · EWY · EWJ · XAU · COPPER를 원클릭 프리셋으로 추가(분할매수 계획 수치 포함), SK하이닉스 같은 자산은 직접 추가
- 가격 소스는 자산별로 **Binance 자동**(비트코인) / **Finnhub 자동**(SPY 2X·QQQ·SOXL·EWY·EWJ — 전부 미국 거래소 상장 티커, 설정에서 본인 무료 키 입력 필요) / **수동 입력**(XAU·COPPER·국내 주식 — Finnhub 무료 티어가 한국거래소를 지원하지 않는 것을 실제 확인함, `stock-api-check.html` 참고)
- **분할매수 계획 트래커**: "720 → 660 달러 / 매 10달러마다 3%씩" 형식을 그대로 입력하면 현재가 기준으로 **몇 단계가 발동됐는지 / 지금까지 채웠어야 할 비중 / 실제 비중과의 차이 / 다음 단계 발동가**를 자동 계산
- 계획 수치가 안 맞으면(단계수 × 단계당 % ≠ 총 목표 %) 경고 표시
- 기준선(구간)은 자산별로 따로 저장. BTC 외 자산은 BTC 기본값을 물려받지 않고 빈 상태로 시작합니다
- A지표 · 실수요 판정 · 매매 장부는 비트코인 전용 분석 프레임이라 BTC 탭에서만 표시됩니다

**6단계 — 기준선 도달 알림**
- 가격이 구간 경계 ±2% 이내로 접근하면 브라우저 로컬 알림(Notification API) 발송, 같은 경계에 머무는 동안 중복 알림 방지
- 근접 기준선 실시간 목록 + 알림 기록(시각·기준선·당시 가격) 저장
- **거래소 API 연동은 구현하지 않음**: 이 앱은 서버 없는 정적 웹앱이라 거래소 API 키를 프론트엔드에 넣으면 브라우저 개발자도구로 누구나 키를 볼 수 있습니다. 안전하게 연동하려면 별도 백엔드 프록시 서버가 필요하며, 이는 지금 구조(서버 없이 브라우저에서만 동작)를 벗어나는 아키텍처 결정이라 사용자 판단에 맡깁니다.

앱은 "사라/팔아라"를 말하지 않습니다 — 조건 충족 여부와 다음에 확인할 지점만 보여주고, 최종 판단은 사용자 몫으로 남깁니다.

이로써 설계 문서의 1~6단계 로드맵이 모두 구현되었습니다 (거래소 API 연동 제외, 사유는 위 참고).

## 아직 구현되지 않은 것

정직하게 남겨둡니다. 설계 문서에 있지만 아직 없는 항목들입니다.

- **국내 주식·원자재 시세 자동화**: SK하이닉스 같은 한국거래소 종목은 Finnhub 무료 티어가 지원하지 않는 것을 `stock-api-check.html`로 실제 확인했고, 그 외에도 CORS를 허용하는 무료·무인증 API가 없어 수동 입력입니다. XAU(금)·COPPER(구리)도 상품 시세라 무료 티어 지원 여부가 불확실해 자동화 보류 상태입니다.
- **개별 지표 차트**: 문서 3-3표의 "권장 시각화 방식" 중 별도 차트로 지정된 항목들(MVRV 시계열, 비트/유동성·금·증시 비율, 장기보유자, 고래매집, 펀딩비 막대, DXY, MSTR NAV, 다이버전스)은 미구현입니다. 현재 수동 지표는 "최신 값" 하나만 저장하고 날짜별 이력을 남기지 않으므로, 시계열 차트를 그리려면 데이터 모델 변경이 선행되어야 합니다.
- **ROI 사이클 진행률 게이지**: 원형/가로바 게이지 대신 텍스트로만 표시됩니다.

## 데이터 소스

가격 데이터는 **Binance 공개 API**(`api.binance.com`, 인증 불필요)의 `klines` 엔드포인트에서 일봉 OHLCV 1000일치를 받아옵니다. 기본 주소가 지역 차단되는 경우 공개 데이터 미러(`data-api.binance.vision`)로 자동 전환됩니다.

CoinGecko를 쓰지 않는 이유: 무료 플랜이 과거 데이터를 **365일까지만** 제공하고(초과 요청 시 HTTP 401), **종가만** 주기 때문에 50주(350일) 이평선과 캔들차트를 그릴 수 없습니다.

`api-check.html`을 브라우저로 열면 이 API들이 현재 환경에서 실제로 접속되는지 바로 확인할 수 있습니다(서버 실행 불필요).
